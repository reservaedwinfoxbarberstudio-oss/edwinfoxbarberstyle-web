## Stack

## Estructura del repositorio

```
/
├── index.html       # Sitio completo (HTML + CSS + JS)
├── _redirects       # Reglas de redirección Cloudflare Pages
├── robots.txt       # Instrucciones para motores de búsqueda
├── sitemap.xml      # Mapa del sitio para SEO
└── README.md        # Este archivo
```

## Deploy automático

Cada push a la rama `main` despliega automáticamente en Cloudflare Pages.
